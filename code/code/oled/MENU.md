# OLED 按键菜单

新版原理图：SW2=BUTTON1=PB4、SW3=BUTTON2=PB5，外部上拉，按下接地。
主循环轮询，30 ms消抖，按住约800 ms触发一次长按；长按释放不再触发短按。

## 操作

- 正常显示时按任意键进入菜单。
- SW2短按：上翻；SW3短按：下翻，选择项以 `+` 标记。
- SW2长按：确认/切换所选项；间隔项进入/结束编辑。
- SW3长按：保存全部菜单配置并退出；写入失败留在菜单显示错误。
- 间隔编辑时，SW2短按减少0.5秒，SW3短按增加0.5秒。
  可设0.5～86400.0秒，到上下限停止；不按预设档位跳变。

## 菜单项目

| 显示 | 功能 |
|---|---|
| BOOT ALL SENSORS / ADC ONLY | 开机OLED显示全部传感器，或只显示四路ADC |
| RECORD START / STOP | 记录开关，保存退出后生效 |
| ORDER NEW FIRST / OLD FIRST | 历史日志导出顺序，保存退出后生效 |
| INT xx.xS | 写Flash的间隔，单位秒、步长0.5秒 |
| CLEAR LOGS | 清空历史记录 |

仅ADC页面采用2倍字号（10×16像素字形，12像素字符间距），四行占满64像素高度。
每行显示 `0:41663.25` 这样的通道编号和两位小数码值；0～3对应IN0～IN3。
最大值 `3:65535.00` 共10字符，占120像素，左右各留4像素，完整显示。
全部传感器页和菜单继续使用原小字号；显示模式切换不改变串口和Flash精度。

清空需要在此项连续两次长按SW2（每次先释放）：第一次显示确认，第二次执行。
翻动菜单会撤销清空确认。清空是即时操作，不需要等保存退出，且不修改记录开关；
记录处于开启状态时，后续仍会继续生成日志。清空保留MCU内部配置和电压标定。

普通设置在菜单中仅修改草稿，不频繁写Flash；长按SW3统一保存到MCU内部Flash，
并更新运行状态。没有改动记录开关或间隔时，不重置原来的记录计时。
开关/间隔改变后，从保存时重新计时。只切换OLED页面，不停止其他传感器采集、
滤波或写入其他传感器字段，也不改变实时串口通道格式。

配置与串口setting共用DataLogger配置区、CRC及存储代码，重启保持。
串口仍提供 `log start/stop`、`log order old/new`、`log clear`；
`log interval 0.5` 或 `log interval 60.5` 支持半秒精度。
`display all`、`display adc` 可通过串口修改同一显示模式，`log info`查看。
串口setting或日志导出期间暂停按键菜单，丢弃尚未保存的按键草稿，避免两边覆盖。

## 计时与兼容

记录调度使用TIM14的毫秒计数，正常ADC仍为100 Hz。保存精确间隔到内部配置
保留字节20～23（毫秒）；旧配置的整数秒自动换算，默认60秒。
显示模式使用保留字节14；旧值0xFF默认全部显示。
电压标定的字节16～19保持独立。历史记录内容和长度不变。

现有RTC日志时间只保存整秒，0.5秒间隔时同一秒可能有两条记录，记录序号不同。
时间间隔是采样/记录目标周期，写Flash在主循环执行；若传感器超时、Flash擦除等
阻塞超过周期，沿用单个待写快照机制，不承诺每个0.5秒周期均无丢帧。
消抖和长按时间也会受主循环阻塞延迟影响，不在中断内操作SPI或Flash。

烧录验证：按键方向、长按不重复、半秒及1.5秒间隔、保存重启保持、
串口与按键配置互通，以及清空后电压标定保留。
