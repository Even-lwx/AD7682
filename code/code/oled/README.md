# SSD1306 128×64 SPI OLED 显示屏

控制器由用户确认是 SSD1306；新版原理图中仅有 7 针排母。
原理图：`pcb/AD7682-Ver1.2-ADC供电传感器供电改为5V/Sheet1.SchDoc`。

| 排母引脚 | 网络 | MCU / 电源 |
|---|---|---|
| 1 | GND | GND |
| 2 | 3V | 3V 电源，不是 ADC 的 5V 电源 |
| 3 | CLK | PA0 / SPI2_SCK |
| 4 | DI | PA4 / SPI2_MOSI |
| 5 | OLED_RES | PB10，低电平复位 |
| 6 | OLED_DC | PB1，低为命令，高为数据 |
| 7 | OLED_CS | PB0，低电平片选 |

## 协议与配置依据

参考：[SSD1306 Rev 1.1，含电荷泵应用说明](https://cdn-shop.adafruit.com/datasheets/SSD1306.pdf)。

- 正文第 16～17 页，8.1.3：四线串行接口，上升沿移入数据，MSB 优先，只写。
- 正文第 52 页，表 13-4：时钟周期最低 100 ns。复用现有 SPI2 模式 0、2 MHz；不修改 Flash 的 SPI 配置。
- 正文第 27 页，8.9：RES# 低脉冲至少 3 μs；启动等待 100 ms，复位低 10 ms，释放后等待 20 ms。
- `AE` 关闭显示后配置：`D5 80` 时钟、`A8 3F` 64 行、`D3 00` 偏移、`40` 起始行。
- `8D 14` 开模块内部电荷泵；此设置适用于使用内部电荷泵的标准 SSD1306 模块。
- `20 02` 页寻址，`A1/C8` 扫描方向，`DA 12` 128×64 交替 COM 配置。
- `81 3F` 对比度、`D9 F1` 预充电、`DB 20` VCOMH（0.77×VCC）。
- `A4/A6/2E` 按显存显示、正常极性、停止滚动。清空 8 页后 `AF` 开显示。

## 显示和调度

8 行分别显示：电池电压与记录开关、SHT41 温湿度、1/2 号气压计的
滑动平均压力、IN0～IN3 滤波 ADC 码（两位小数，不是伏特）。
数据显示目标每100 ms更新一次（10 Hz）。暂时未得到有效传感器结果时，沿用应用层的无效值标记。

仅使用 176 字节文字缓冲，没有 1024 字节整屏缓冲。每次主循环最多发送一页
128 字节，页间隔至少 1 ms。页地址每次重新设置，可与 Flash 事务交替。
SPI 操作均在主循环中执行；每次传输后释放 OLED 片选，包括错误路径。
Flash 片选低或 SPI 忙时不发送。初始化先拉高 OLED CS，避免 Flash 初始化数据误入屏幕。

先执行待写日志、串口命令和传感器处理，再刷新显示；日志导出和 ADC 诊断时暂停刷新。
OLED 传输不关闭中断，TIM3 的 SPI1 ADC 采样与 USART 接收中断仍可执行。
显示失败不会阻止传感器和 Flash 流程；单页传输错误丢弃当前帧，下一帧整帧重写。
SPI 无应答，因此返回 HAL_OK 仅表示 MCU 发送成功，不能证明屏幕已连接。

启动阶段最多重试初始化 3 次。启动 ADC 定时器之前直接显示
`SSD1306 READY / WAITING FOR SENSORS`，不依赖传感器读取和滤波就绪。
串口 `OLED SPI TX OK (NO ACK)` 表示初始化 SPI 发送成功；
`OLED SPI INIT TX ERROR` 表示 MCU 端初始化发送失败。
正常刷新不再要求传感器请求标志为零，以避免连续请求使显示长期得不到刷新。
单次 SPI 发送超时设为 25 ms，允许被 ADC 中断抢占；正常页数据线传输约 0.512 ms。

## 验证

Keil 编译检查通过；实际点亮、显示方向和供电干扰需烧录到新版硬件确认。
OLED 自身扫描和电荷泵会增加电源活动，软件调度不能保证其不会影响模拟噪声。

10 Hz调度：主循环在传感器读取前、后分别尝试发送一页，避免持续传感器请求
把8页帧拖到8轮主循环。仍优先待写日志，导出/诊断暂停显示；主循环阻塞
可能降低实际刷新率，100 ms为帧启动最小间隔，不是已测得的硬件帧率。
