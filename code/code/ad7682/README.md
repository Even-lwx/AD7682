# AD7682 driver

This driver targets the AD7682 connection in the project schematic:

- SPI1 SCK: PA1 (`SCK`)
- SPI1 SDO: PA6 (`SDO`)
- SPI1 DIN: PA7 (`DIN`)
- Conversion start (`CNV`): PA5

The AD7682 has no register map. A conversion is started by a CNV high pulse;
after the conversion interval, two MSB-first SPI bytes are read. The driver
uses the STM32 HAL SPI handle generated by CubeMX and is intended for the
blocking single-conversion path first. The reference voltage passed to
`AD7682_Init` must be the measured voltage on the ADC REF pin.
