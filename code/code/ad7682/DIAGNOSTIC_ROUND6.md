# 自动干扰诊断（第 6 版）

每次上电自动测 IN2，再测 IN1；每路 29 阶段，每阶段 96 组，每组 5 个
原始码。沿用 FireWater 的 `ADC:` 前缀、12 个数值字段。请在复位前开始
录制，接线与上一轮保持一致，录约 4 分钟并包含 I0=999 后的正常数据。
无需命令。阶段 0～17 与第 5 版条件相同。

## 新增阶段

| 阶段 | IN1 标识 | IN2 标识 | 条件 |
| --- | --- | --- | --- |
| 18 | 118 | 218 | 64 MHz，气压计原有配置，基准 |
| 19 | 119 | 219 | 仅 U7 Power-down |
| 20 | 120 | 220 | 仅 U11 Power-down |
| 21 | 121 | 221 | 两个气压计均 Power-down |
| 22 | 122 | 222 | 恢复原配置、64 MHz，重复基准 |
| 23 | 123 | 223 | HSI 直接驱动 CPU，16 MHz，PLL 保持运行 |
| 24 | 124 | 224 | HSI 直接驱动 CPU，16 MHz，PLL 停止 |
| 25 | 125 | 225 | 重复 HSI 16 MHz、PLL 运行 |
| 26 | 126 | 226 | 恢复 64 MHz，重复基准 |
| 27 | 127 | 227 | HSI 16 MHz、PLL 停止、两个气压计均 Power-down |
| 28 | 128 | 228 | 恢复 64 MHz、气压计原有配置，最终基准 |

新阶段 SPI 保持 2 MHz，TIM2 保持 1 MHz，组周期保持 20 ms，CNV 拉低后
等待保持 500 us。每个新阶段配置后等待 250 ms 再采样。实际 CNV 时间
和组内偏移仍记录在数据中，分析应使用实际时间而非假定指令开销相同。

LPS22HH 依据手册 DocID030890 Rev2 第43页：CTRL_REG1(10h) 的
ODR[6:4]=000 停止自主压力/温度转换，I2C 仍可访问。这与只停止 MCU
读取不同，也不等同于切断芯片电源。保存两颗芯片原始 CTRL_REG1，只
清除 ODR 位，写入后读回整个寄存器核对。每阶段后恢复原始配置并读回
确认，恢复失败最多重试三次。所有软件 I2C 配置操作在 64 MHz 进行。

PLL 对照直接使用现有 MCU 的 HSI，无需外部时钟接线。必须先切到 HSI
才能关闭 PLL。恢复时显式重建原来的 HSI/1×8/2 PLL 参数，因为本工程
HAL 关闭 PLL 会清除其源选择及输出使能位。启停 PLL 使用 HAL 有界超时，
等待期间保留 SysTick 中断，避免时钟失败时超时无法退出。

HSI 在全部阶段仍然运行，因此本轮不能排除 HSI 本身的耦合，也无法
通过软件独立切断传感器供电或外部参考源。PLL 开/关会同时改变芯片
功耗，若结果变化，仍需区分直接时钟耦合与电源耦合。

## 日志

原始数据行字段与前版完全一致，I0=通道×100+阶段。

- 990：版本 6、29 阶段、96 组等启动参数。
- 991：沿用第 5 版，最后两项为实际 HCLK Hz 与时钟切换状态。
  切换状态位 1=RCC/频率、2=UART 初始化、4=UART 接收、8=SPI2 初始化，
  本轮新增 16=PLL 启停或就绪校验失败。
- 993：新增阶段配置读回。I1=阶段标识，I2=Power-down 请求掩码
  （1=U7、2=U11、3=两颗），I3=气压计配置错误掩码（同上），
  I4/I5=实际 U7/U11 CTRL_REG1，I6/I7=保存的原始值，I8=时钟模式
  （0=PLL64、1=PLL32、2=HSI16且PLL开、3=HSI16且PLL关），
  I9=PLL 就绪标志，I10=实际 HCLK Hz，I11=CPU 是否直接使用 HSI。
  原始 CTRL_REG1 通常为 66（0x42），Power-down 后通常为 2（0x02），
  但以保存和读回值为准。读取失败显示 255，并设置错误掩码。
- 994：新增阶段结束的恢复确认。I1=阶段标识，I2=时钟恢复状态，
  I3=气压计恢复状态，I4/I5=恢复后的 CTRL_REG1，I6=实际 HCLK Hz，
  其余为 0。正常时两个恢复状态均为0、HCLK 为64000000。
- 999：全部完成，I1=最终 HCLK Hz，正常为64000000。

原始行状态 I11 原有含义不变，1024 表示时钟配置/恢复错误，新增
2048 表示气压计配置/读回/恢复错误。异常阶段不能当作有效对照。
所有总线操作与串口输出均在捕获窗口之外，捕获期间不读取其他传感器
或访问 Flash。新阶段结束先恢复时钟和气压计，再输出缓存。

## 正常工作与内存

测试完成恢复四路每路100 Hz、100点时间中值加25点滑动平均。滤波
缓冲重新填满后使用，小数计算与串口两位小数保留。W25Q128 继续按
设定间隔保存带0.01码精度的滤波结果，记录写入优先于实时输出。
测试期间不写正常记录，记录间隔从测试完成重新计时。
诊断和滤波缓冲继续共用 RAM，切换时清空滤波状态和待写标志。
UART 在时钟切换时重新校准并重新开启接收，等999后再发送设置命令。
