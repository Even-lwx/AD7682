# 当前正常采样滤波

四路分别以100 Hz更新：100点滑动中位数 → 一阶低通 → 一阶低通。
替代原来的中位数后25点滑动均值，其他采样及通道切换流程保持原样。

两级均取时间常数0.2秒，alpha=1-exp(-0.01/0.2)=0.0487705755。
第一级输入中位数，第二级输入第一级最新结果；使用float保留小数。
窗口满100个成功样本后，以当前实际中位数初始化两级状态，不从0爬升。
读取失败沿用之前有效结果，不推进该通道滤波；复位/诊断结束重建窗口。

串口、OLED和Flash均取g_adc_filtered_codes，同一结果按各自格式输出/保存。
0.5秒或1秒记录间隔不会改变100 Hz滤波参数。

两级低通本身阶跃90%响应约0.78秒、低频延迟约0.4秒；
100点中位数对理想阶跃还增加约0.5秒延迟。
该模型平滑中心趋势，不保证删除持续偏移；污染超过半窗时中位数会跟随。
未添加固定值钳制、永久冻结或异常值替换。需要用烧录后原始/滤波同步日志
验证平滑度与真实变化响应，不能把离线快照重放当作完整100Hz实测。

验证：Keil编译；float32模型检查分数常量启动、阶跃单调无过冲及90%响应时间，
100点中位数在49个同方向离群样本下仍保留基线。
