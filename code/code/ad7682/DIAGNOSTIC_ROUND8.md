# 电阻分压 IN0 与传感器 IN1 对照（第 8 版）

本轮沿用第7版的11种GPIO速度条件、三段重复、时间戳及配置读回，
只把上电自动测试的第一通道从IN2换成IN0，第二通道仍是IN1。
其余字段和恢复流程见 DIAGNOSTIC_ROUND7.md。

## 接线和预期

- 2.5 V节点经10 kΩ连接IN0，IN0再经10 kΩ连接板上模拟地。
- 理想分压约1.25 V，戴维南等效源电阻5 kΩ。
- ADC实际参考为2.5 V时，理想原始码约32768；以实际电压、参考和电阻误差为准。
- IN1保持原传感器接线。测试时不再改动接线。
- 分压器仍会受到2.5 V源、参考、地和ADC采集负载影响，不能视为绝对无噪声源。
- 如果分压上端恰好就是ADC的REF，比例测量会抵消部分共同参考变化。
  IN0没有尖峰也不能完全排除参考源对IN1的影响。

## 自动运行及日志

复位前启动FireWater CSV录制，录约4分钟并包含999后的正常数据。
不需要发送串口命令。

- 990：I1版本8，I5第一通道0，I6第二通道1，其余参数沿用第7版。
- IN0数据行I0为29～39，分别对应第7版IN2的229～239。
- IN1数据行I0仍为129～139。
- 每行I2～I6是5个未滤波原始码。I1和I7～I10的时间戳含义不变。
- 995/996仍标识每个独立的96行采集块及GPIO设置/恢复状态。
- 992表示开始IN1，999表示完成并恢复正常模式。

两通道顺序采集，不是同时采样，不能据此判断两个通道的尖峰是否同步。
分析重点是两路是否均有类似幅度、持续长度及周期特征的异常。
IN0如有相似尖峰，说明原IN1传感器不是产生这类异常的必要条件；
仍需继续区分输入源、ADC/参考/地耦合和数字采样路径。

测试完成后继续原有四通道100 Hz、100点中值加25点滑动平均，
正常串口输出及W25Q128定时存储流程保持原样。诊断原始码不写入正常记录。
