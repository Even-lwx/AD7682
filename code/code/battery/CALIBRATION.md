# 电池电压标定

MCU ADC参考为3.3 V，12位，上臂100 kΩ、下臂47 kΩ。
AD7682外部参考为5 V，与电池检测标定独立。

供电稳定后等待至少5秒，使三点中值及50点均值充分更新。
万用表测电池正负极之间的实际电压（不是分压后的ADC引脚电压），例如8.120 V。
串口命令以回车换行结束：

```
setting
battery info
battery cal 8.120
battery info
exit
```

- `battery info`：显示MCU参考、分压阻值、校正系数、电压和读数是否新鲜。
- `battery cal VOLTS`：单点增益标定，接受2.500～8.600 V，最多3位小数；
  必须有最近2秒内的成功采样，系数限制0.5～1.5，避免明显输入错误。
- `battery reset`：恢复系数1，使用3.3 V理论换算，并保存。

系数=万用表电池端实测电压÷未标定的滤波电压。滤波窗口保留理论电压，
输出时统一乘系数，因此更新系数后无需等待旧滤波值退出窗口，也不会重复叠乘。
串口、OLED、后续Flash电池记录与电量灯统一使用校正结果。
历史日志不会重写。电池节数仍沿用上电识别并锁定的策略。

参数存于MCU内部Flash原配置记录的保留字节16～19，以百万分之一单位保存，
与日志开关、记录间隔和输出顺序一同保存并由原CRC保护。
旧配置该字段为擦除值时默认系数1；`log clear`及掉电复位不会清除标定。
重新烧录时若烧录器擦除了内部配置页，则需重新标定。

此为单点增益校正，不校正非线性、零点偏移或动态供电扰动。
