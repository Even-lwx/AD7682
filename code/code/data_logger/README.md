# 日志记录控制

串口每条命令以 `\r\n` 结束。在 `setting` 模式下使用：

当前串口配置：**921600、8位数据、Even偶校验、1位停止位（8E1）**。
VOFA+ 文本发送需启用实际的 CRLF，HEX 测试 `setting` 为 `73 65 74 74 69 6E 67 0D 0A`。

接收使用 USART1 RX + DMA1 Channel1 循环缓冲（128字节），DMA在ADC屏蔽CPU中断时仍可搬运数据，主循环解析完整行。保持一次发送一条命令并等待响应；连续输入超过128字节、主循环尚未来得及处理时会报告溢出并丢弃待处理指令，需重新发送。

复位后会输出 `UART RX DMA128 READY: 921600 8E1 (2026-11-04)`，用于确认固件版本。
`uart info` 可在普通或 setting 模式下查看已处理字节数，以及 parity（偶校验）、frame（帧）、overrun（溢出）、noise（噪声）累计错误数。
接收错误时会限速输出 `UART RX ERROR`，丢弃尚未执行的指令并重启DMA；错误指令需要电脑重新发送。若出现 `UART RX START ERROR`，表示DMA未能启动。

发送文本仍为原格式；HAL发送失败后整段重发一次。若第一次只发出部分内容，上位机可能看到残留片段；没有ACK/NACK协议，无法确认电脑是否成功接收。

```text
setting
log stop
log info
log start
exit
```

- `log stop`：停止新增历史记录，取消尚未写入的待记录数据。采样、滤波和退出 setting 后的实时输出继续运行，已有日志保留。
- `log start`：开始记录，从本次开启时刻重新计算记录间隔；到达设定间隔后写第一条，不补写停止期间的数据。已经开启时重复发送不会重置计时。
- `log info`：原有信息后增加 `recording=on/off`。
- 开关状态与间隔、导出顺序一起保存在 MCU 内部 Flash；`log clear` 不删除这些配置。旧配置或无配置时默认开启，兼容原来的自动记录行为。
- 开关保存失败会回复 `LOG RECORDING CONFIG ERROR`，原状态保持不变。

## 按时间段导出

在 `setting` 模式下，指定起止日期时间：

```text
setting
log dump 2026-11-02 09:00:00 2026-11-02 10:30:00
exit
```

- 等导出结束后再发送 `exit`；提前发送会取消本次导出。
- 日期使用设备 RTC 的时间，支持 `YYYY-MM-DD HH:MM:SS` 和与 `SET` 相同的 `YY-MM-DD HH:MM:SS`，年份范围为 2000～2099。两个时间之间用一个空格分隔，可跨天、跨月、跨年。
- 包含起止秒内的全部记录；起止相同可导出该秒的记录（包括 0.5 秒间隔下的多条记录）。开始晚于结束、无效日期或格式错误时返回 `LOG DUMP ERROR`，正在进行的导出继续。
- 导出仍遵循 `log order old` / `log order new`，每行沿用原 `samples:` 格式；不带时间的 `log dump` 仍导出全部记录。
- 按时间段导出完成后返回 `LOG DUMP DONE: matched=N read_errors=M`。`matched=0` 表示没有匹配记录；`read_errors` 表示读取失败的记录数（例如导出期间旧记录被循环覆盖）。空日志也会立即返回完成信息。
- 按每条记录实际保存的日期时间筛选，逐条扫描导出开始时已有的日志。设备校时前后日期不连续也会检查，不会按时间排序提前停止；记录很多时需等待扫描完成。时间无效的记录不参与时间段导出，导出期间新增的记录不混入本次结果。

例如导出跨午夜的一段数据：

```text
log dump 2026-11-01 23:50:00 2026-11-02 00:10:00
```

## 选择 ADC 码值或压力（hPa）

```text
setting
log dump raw
```

`log dump raw` 导出日志中的四路 ADC 码值。`log dump hpa` 将四路 ADC 字段换算成 hPa 后导出；也支持叠加时间段：

```text
log dump hpa 2026-11-02 09:00:00 2026-11-02 10:30:00
log dump raw 2026-11-02 09:00:00 2026-11-02 10:30:00
```

每次等本次导出结束再发送下一条命令；`exit` 会取消导出。不指定模式的 `log dump`（含时间段）默认导出 ADC 码值，每条命令独立选择模式。模式仅作用于本次导出，不保存到 Flash。

按用户提供的 IPNZAA135KP-4428-A1 厂家表格及确认的 **kPa** 单位：

```text
V = ADC码值 × 5.0 / 65536
P(kPa) = 25 × V + 22.5
P(hPa) = 250 × V + 225
```

| 输出电压 | 压力（kPa） | 导出压力（hPa） |
| --- | --- | --- |
| 0.5 V | 35 | 350 |
| 1.5 V | 60 | 600 |
| 3.0 V | 97.5 | 975 |
| 4.5 V | 135 | 1350 |

- 使用当前固件配置的 AD7682 外部参考电压 **5 V**（与 MCU 的 3.3 V 不同），码值比例为 `/65536`。参考电压宏与 ADC 初始化共用。此换算假定输入为上述型号的传感器输出，四路采用同一关系；更换传感器或参考电压后需相应调整。
- 历史日志中的 ADC 是**滤波后的码值**（当前保留 0.1 码），不是滤波前的单次采样。`raw` 表示导出原存储码值，`hpa` 也从这份码值换算，不能恢复未保存的滤波前数据。
- 导出数据仍为 `samples:` 和原来的 15 个字段：年、月、日、时、分、秒、温度、湿度、U7压力、U11压力、ADC0、ADC1、ADC2、ADC3、电池电压。hPa 模式只将第 11～14 个字段改为对应通道的 hPa，保留两位小数；U7/U11 压力原本就是 hPa。
- 显式选择模式时先输出 `LOG DUMP ADC:` 单位说明。hPa 模式无论是否带时间段，结束后均输出 `LOG DUMP DONE`；空日志立即完成。
- 无效 ADC（如 `-9999`、`65535`）导出压力仍为 `-9999.00`，不会换算成正常压力。不按 350～1350 hPa 钳位，沿用表格的线性关系，0 V 对应 225 hPa、5 V 对应 1475 hPa；没有额外减去大气压。
- 换算只发生在 MCU 导出时，Flash 继续保存码值。已有日志没有保存参考电压/传感器型号，因此采用其他参考电压或其他传感器采集的旧日志不能直接套用当前关系。

## 温湿度滤波和存储

SHT41 每次成功读取后，温度、湿度分别经过三点中值，再进入50点滑动平均。仅接受通信成功、温度 −40～125℃、湿度0～100%RH的数据；无效值不进入窗口。窗口未满时按实际样本数平均，不补零。窗口是50次有效读取，并非固定50秒。

串口温湿度字段与历史记录使用同一份滤波结果。浮点计算保留小数，实时串口输出三位小数，Flash沿用原记录格式保存0.01℃、0.01%RH精度。读取连续失败时保持最近结果最多5秒，超时后使用无效标记；恢复有效读取后重新建立滤波窗口。

滤波可抑制孤立尖峰并平滑短时波动，不能消除焊接余热等真实慢变化。可以先 `log stop` 等设备稳定，再 `log start` 正式记录。
