# 日志记录控制

串口每条命令以 `\r\n` 结束。在 `setting` 模式下使用：

```text
setting
log stop
log info
log start
exit
```

- `log stop`：停止新增历史记录，取消尚未写入的待记录数据。采样、滤波和退出 setting 后的实时输出继续运行，已有日志保留。
- `log start`：开始记录，从本次开启时刻重新计算记录间隔；到达设定间隔后写第一条，不补写停止期间的数据。已经开启时重复发送不会重置计时。
- `log info`：原有信息后增加 `recording=on/off`。
- 开关状态与间隔、导出顺序一起保存在 MCU 内部 Flash；`log clear` 不删除这些配置。旧配置或无配置时默认开启，兼容原来的自动记录行为。
- 开关保存失败会回复 `LOG RECORDING CONFIG ERROR`，原状态保持不变。

## 温湿度滤波和存储

SHT41 每次成功读取后，温度、湿度分别经过三点中值，再进入50点滑动平均。仅接受通信成功、温度 −40～125℃、湿度0～100%RH的数据；无效值不进入窗口。窗口未满时按实际样本数平均，不补零。窗口是50次有效读取，并非固定50秒。

串口温湿度字段与历史记录使用同一份滤波结果。浮点计算保留小数，实时串口输出三位小数，Flash沿用原记录格式保存0.01℃、0.01%RH精度。读取连续失败时保持最近结果最多5秒，超时后使用无效标记；恢复有效读取后重新建立滤波窗口。

滤波可抑制孤立尖峰并平滑短时波动，不能消除焊接余热等真实慢变化。可以先 `log stop` 等设备稳定，再 `log start` 正式记录。
