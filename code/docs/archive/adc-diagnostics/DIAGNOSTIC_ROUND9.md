# 第 9 轮：连续单通道原始采样与真实 CNV 时间

## 使用

上电不自动测试。保持当前接线，在串口工具开始录制 FireWater CSV 后发送：

```
setting\r\n
adcprobe 1\r\n
```

`1` 指芯片 IN1，可改为 0、2、3。命令也可在正常模式直接发送。
每次只测试指定一路，不轮询其他通道。不要在日志导出期间启动。
测试约需一分钟，准确时长取决于输出耗时；记录至 I0=999。
测试过程中不处理配置命令，完成后再发 `exit\r\n` 恢复实时输出。
如果在正常模式启动，则完成后自动恢复实时输出。

## 条件

不改变外部参考、GPIO 速率、SPI 分频或驱动内部转换时序。
正常 CNV 拉低后等待仍为 100 us；测试只改变连续有效转换之间的调度间隔。
SysTick、TIM14 和 UART RX 中断保留。
每块开始前建立通道配置，发送元数据，然后等待 250 ms。
每块 288 个连续原始样本，捕获期间不发送 UART、不读其他传感器、不访问 Flash。
捕获结束才发送整块数据，块间存在发送及静默等待间隔，不是无间断长录波。

| 阶段 I6 | 标识 I0（IN1） | 采样节奏 | 每块有效采样跨度（约） |
|---|---|---|---|
| 0 | 140 | 固定 10 ms，100 Hz | 2.87 s |
| 1 | 141 | 确定性伪随机 5～15 ms，平均约 10 ms | 约 2.87 s |
| 2 | 142 | 固定 1 ms，1 kHz | 0.287 s |
| 3 | 143 | 固定 4 ms，250 Hz | 1.148 s |
| 4 | 144 | 五点一组，组内 1 ms，末点至下组首点 46 ms | 约 2.85 s |
| 5 | 145 | 重复固定 10 ms 基准 | 2.87 s |

每阶段连续执行三块后自动进入下一阶段。所有通道标识为 `通道*100+40+阶段`。
变化间隔通过固定种子的 LCG 生成，不使用传感器数据作为随机源。
突发采样的组首间隔 50 ms，平均每秒约 100 次有效转换。
首次采样在块计时开始约 1 ms 后；以 I1 的实际 CNV 时间为分析依据。

## FireWater 格式

仍使用 `ADC:` 前缀，每行固定 12 个数值。本轮布局与前轮不同，以版本 9 区分。

原始数据行：

| 字段 | 含义 |
|---|---|
| I0 | 通道*100+40+阶段 |
| I1 | CNV 时间，距本块计时起点的 us，分辨率 1 us |
| I2 | 原始 ADC 码，没有滤波 |
| I3 | 状态：0 正常，1 驱动错误，2 超时，256 调度迟到，可按位组合 |
| I4 | 块内样本索引 0..287 |
| I5 | 通道 0..3 |
| I6 | 阶段 0..5 |
| I7 | 块编号 1..3 |
| I8..I11 | 保留，0 |

时间戳沿用驱动 `last_cnv_us`，在 CNV 写高前读取，存在固定的寄存器访问延迟。
SPI 失败时 I2=65535，I1 改用调用前时间，不是真实有效转换时间。
256 表示调用开始比目标时间迟超过 100 us，或本次读取完成时已错过下一目标；
后者放弃追赶，下一点从当前时间重新排期。分析应检查实际时间差，错误样本不作为物理尖峰。

事件行：

- 990：I1=版本9，I2=阶段数6，I3=288点，I4=每阶段3块，I5=通道，I6=等待100us，I7=名义SPI 2MHz，其他0。
- 991：I1=本块标识，I2=块号，I3=288点，I4=阶段，I5=等待100us，I6=通道预热状态，I7=HCLK Hz，I8=SPI Hz，其余0。
- 999：I1=版本9，其余0，表示完成并恢复正常采样。

检查每个阶段三块是否齐全、每块 I4 是否完整、I3 是否为0。
块间不能直接拼接时间戳，也不能根据串口接收间隔推断采样频率。
各阶段覆盖的真实时间不同，不能直接按尖峰总数比较，应结合时间跨度和每点采样时刻分析。
每块时间较短且有发送空档，这轮不能单凭 FFT 峰值证明唯一物理干扰频率。

## 正常模式保护

诊断与滤波共用 RAM，测试期间暂停正常采样/记录，丢弃已有待写标志。
测试结束清空诊断缓存和四路滤波结果，恢复四路每路100Hz。
正常输出和记录需重新填满100点原始窗口；记录间隔从测试结束重新计时，不补写测试空档。
保留原来的 `log start/stop` 状态、记录间隔、排序设置和外部参考配置。
诊断数据不存入 W25Q128，正常写入仍使用滤波 ADC 数据。
旧的 `adcdiag 0..3` GPIO 对照测试保留，本轮使用独立 `adcprobe` 命令。
